# Six-page Track A report

The report is [`output/pdf/CardioScope-Track-A-Report.pdf`](../../output/pdf/CardioScope-Track-A-Report.pdf). It is generated by [`report_source.py`](report_source.py).

- **Metrics** come from [`CLAIMS.json`](CLAIMS.json), which records the saved aggregate final-evaluation file and its SHA-256. The builder checks that hash before rendering.
- **Screenshots** come from [`docs/images/`](../images/). Their hashes and the outputs visible in each capture are recorded in [`provenance.json`](../images/provenance.json), and the builder checks them as well.
- **Scope:** the builder runs no inference, fitting or evaluation.

Rebuild it in a disposable document environment. Do not install these packages into the frozen product `.venv`:

```sh
python3 -m venv .runtime/submission-report
.runtime/submission-report/bin/python -m pip install reportlab==4.4.9 Pillow==12.3.0 pypdf==6.10.0
.runtime/submission-report/bin/python docs/report/report_source.py
```

The builder asserts that the PDF has exactly six pages, and that every text block and figure stays inside its page.
